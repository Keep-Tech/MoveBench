参与评测

PARTICIPATE IN MOVEBENCH

  1. 生成模型答案

    下载 questions.json，用本地模型或 API 完成全部 140 题。Student 输入仅使用问题，不使用参考答案和评分细则。

  2. 提交完整答案

    按提交模板填写答案、精确模型版本和生成设置，通过 GitHub Pull Request 提交至 submissions/。请勿在公开文件中填写 API Key。

  3. 评分审核后上榜

    维护者在本地调用云端三 Judge，审核逐题评分证据，再更新公开版榜单。当前采用维护者审核流程，提交后不会即时自动评分。
