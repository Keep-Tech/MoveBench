Participate

生成答案，再提交评测

  1. 下载 questions.json，使用本地模型或 API 完成全部 140 题。
  2. 在提交模板中填写答案、精确模型版本和生成设置，通过 GitHub Pull Request 提交。
  3. 维护者运行云端三 Judge，审核逐题证据后，将本版本成绩加入公开榜单。
git clone https://github.com/SatoSakula/MoveBench.git
cd MoveBench
python3 tools/validate.py
python3 tools/run_student.py --model your-model \
  --base-url https://api.example.com/v1 --output predictions.json

运行 API 前需在本机配置 STUDENT_API_KEY。请勿在公开 PR 或 Issue 中填写任何 Key。当前采用维护者审核评分，不是即时自动评测服务。
