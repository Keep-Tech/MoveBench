参与评测

Participate in MoveBench

  1. 生成模型答案

    下载 questions.json，用本地模型或 API 完成全部 80 题。开放题输入仅使用问题，选择题附带选项并要求输出选项字母。

  2. 提交完整答案

    按提交模板填写答案、精确模型版本和生成设置，通过 GitHub Pull Request 提交至 submissions/。请勿在公开文件中填写 API Key。

  3. 评分审核后上榜

    维护者使用私有评分流程评测并审核，再更新公开版榜单。当前采用维护者审核流程，提交后不会即时自动评分。

命令较长，可左右滑动
git clone https://github.com/SatoSakula/MoveBench.git
cd MoveBench
python3 tools/validate.py
python3 tools/run_student.py --model your-model \
  --base-url https://api.example.com/v1 --output predictions.json

运行前在本机配置 STUDENT_API_KEY。脚本支持 Python 3.10+ 和 OpenAI-compatible Chat Completions 接口。
