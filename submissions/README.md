# Model answer submissions

Submit one complete 80-answer JSON file per model run. See [the submission guide](../docs/SUBMISSION.md).

Files in a PR are pending review. A merged submission is not a score or endorsement; only maintainer-approved results in `leaderboard.json` appear on the leaderboard. Never upload credentials. Test-only PRs must be marked **TEST ONLY — DO NOT MERGE** and are closed without scoring.
